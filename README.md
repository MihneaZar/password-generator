## Description
GUI version of the Password Generator, with the help of the [Kivy library](https://kivy.org/).

## Information
Please read the full explanation on [the main branch](https://github.com/MihneaZar/password-generator).
This version was written with the help of the [Pydroid](https://pydroid.app/) IDE, but should be buildable into an apk since it is purely Kivy with a few standard python libraries.
